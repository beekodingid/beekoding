Arsitektur Studio • Alur Kerja Sistem Game

Alur Arsitektur: Setup ➔ Quest ➔ Evaluasi ➔ Reward 🗺️

Setiap fitur di dalam game petualangan selalu mengikuti 4 tahapan arsitektur terstruktur ini agar mudah dikembangkan bersama tim:

  1. 1️⃣ Setup Awal: Siapkan variabel, List, dan tampilan awal panggung
  2. 2️⃣ Interaksi Pemain: Pemain menjelajah, mengumpulkan item, atau melawan Boss
  3. 3️⃣ Evaluasi Logika: Sistem memeriksa syarat (3-Step Demo Pitching & Demo Mode Hotkey)
  4. 4️⃣ Reward & Progres: Buka area baru, tampilkan efek kemenangan, dan lanjut ke tahap berikutnya!

Klinik QA & Debugging • Solusi Bug Game Jam
⏱️ Menit ke 74–82

Dokter Kode: Inspeksi Kualitas Game (QA) 🐛

Sebelum game kita dipamerkan ke orang tua dan teman-teman, mari kita periksa bug yang sering terjadi dan cara memperbaikinya dengan tepat:

  • 🔍 Periksa konsistensi nama variabel, List, dan pesan Broadcast
  • 🔄 Pastikan semua data di-reset saat bendera hijau diklik
  • 🤝 Lakukan uji silang (cross-testing) dengan teman satu tim!
❌ BUG UMUM DI TEMUKAN:
Saat demo di depan juri, waktu habis karena harus bermain terlalu lama dari level 1 untuk menunjukkan Boss di akhir.
✅ SOLUSI DOKTER KODE:
Pasang tombol pintas (Shortcut Key 1, 2, 3) khusus Mode Presentasi untuk melompat langsung ke fitur unggulan ✅
