Peta Layar Komputer: Koordinat X & Y 🗺️

Di dalam panggung Scratch, setiap posisi memiliki alamat rahasia yang disebut Koordinat! Sama seperti alamat rumah, koordinat memberi tahu sprite harus berada di mana.

  • ↔️ Sumbu X (Horizontal): Kiri (-240) sampai Kanan (+240)
  • ↕️ Sumbu Y (Vertikal): Bawah (-180) sampai Atas (+180)
  • 🎯 Titik Pusat (0, 0): Tepat di tengah layar panggung!
  • 💡 Ingat: Ke ATAS nilainya POSITIF (+), ke BAWAH nilainya NEGATIF (-)
Y = +180 (Langit Atas)
Pusat (0, 0)
X = -240 (Kiri)
X = +240 (Kanan)
Y = -180 (Dasar Tanah)

Logika Apel Jatuh: Mengurangi Nilai Y ⬇️

Bagaimana cara membuat apel jatuh ke bawah secara terus-menerus? Kuncinya adalah mengurangi nilai posisi Y apel sedikit demi sedikit dalam perulangan selamanya!

  • 🔄 Gunakan blok forever (selamanya)
  • 📉 Masukkan perintah change y by (-6)
  • ⚡ Semakin besar angka negatif (misal: -10), semakin cepat apel jatuh!
  • 🤔 Tapi apa yang terjadi jika apel menyentuh batas paling bawah panggung?
📦 Kode Blok Scratch Apel:
when 🏴 clicked
forever {
  change y by (-6)
}

💡 Setiap sepersekian detik, posisi apel turun 6 langkah ke bawah!

Kembali ke Langit: Teleportasi Apel 🔄

Jika apel dibiarkan jatuh, ia akan tersangkut di dasar layar. Kita butuh logika deteksi: jika apel sudah sampai paling bawah, pindahkan kembali ke atas di posisi acak!

  • 🔍 Deteksi batas bawah: if <y position < -160>
  • 🚀 Teleportasi ke langit atas: y: 170
  • 🎲 Posisi horizontal acak: x: (pick random -200 to 200)
  • ✨ Hasilnya: apel seolah-olah tidak pernah habis berjatuhan!
📦 Kode Teleportasi Apel:
if <y position < -160> then
  go to x: (pick random -200 to 200)
            y: (170)

Mangkuk Penangkap: Mengikuti Mouse X 🥣

Sekarang giliran mangkuk penangkap! Kita ingin pemain bisa menggeser mangkuk ke kiri dan kanan dengan sangat halus dan responsif mengikuti kursor mouse.

  • 🖱️ Mangkuk hanya bergerak ke samping (Horizontal), tidak boleh terbang ke atas!
  • 🔒 Kunci posisi Y di dasar layar: misal y = -140
  • ⚡ Hubungkan nilai X dengan sensor mouse: set x to (mouse x)
  • 🎮 Rasakan kendali yang sangat instan dan akurat!
🥣 Kode Sprite Mangkuk (Bowl):
when 🏴 clicked
set y to (-140)
forever {
  set x to (mouse x)
}

Hap! Deteksi Tabrakan & Suara Makan 🔊

Saat apel menyentuh mangkuk, game harus tahu bahwa pemain berhasil menangkapnya! Kita buat apel memainkan suara 'Chomp' lalu kembali ke atas sambil menambah skor!

  • 🤝 Deteksi sentuhan: if touching [Bowl] then
  • 🎵 Mainkan efek suara renyah: start sound [Chomp]
  • ➕ Tambah skor pemain: change [Skor] by (1)
  • 🚀 Lempar apel kembali ke atas: go to x: random y: 170
📦 Kode Lengkap Tangkap Apel:
if <touching [Bowl]?> then
  start sound [Chomp]
  change [Skor] by (1)
  go to x: (pick random -200 to 200) y: (170)

Dokter Kode: Tips Memperbaiki Bug 🐛

Saat membuat game, programmer hebat tidak pernah takut dengan error. Mari kita pelajari 2 masalah umum dan solusinya!

  • 🐛 Bug 1: Apel berhenti di bawah layar dan tidak naik lagi.
    Solusi: Cek tanda pembanding. Pastikan tandanya < (kurang dari -160).
  • 🐛 Bug 2: Mangkuk bisa melayang ke atas langit.
    Solusi: Jangan gunakan go to mouse-pointer! Kunci Y dengan set x to mouse x.
  • 🐛 Bug 3: Skor bertambah 10 kali dalam satu tangkapan.
    Solusi: Langsung pindahkan apel ke langit segera setelah touching mangkuk!
🛡️ Resep Rahasia Bebas Bug:

Selalu letakkan blok Teleportasi di dalam kondisi touching mangkuk, sehingga apel langsung menghilang dari area kontak mangkuk!
