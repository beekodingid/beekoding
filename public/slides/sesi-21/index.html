Mengapa Kita Butuh User Experience & Kontrol Audio? 🤔

Game yang hebat harus memikirkan kenyamanan pemainnya. Musik membuat game menyenangkan, tetapi pemain juga harus punya kebebasan mematikan suara kapan saja!

  • 🎵 BGM (Background Music): Musik yang berulang terus menerus di latar belakang
  • 🔊 SFX (Sound Effects): Efek suara aksi singkat seperti lompat atau koin
  • 🔘 Tombol Toggle Mute: Tombol switch ON / OFF di sudut layar
  • 👂 Kenyamanan bermain: Tidak memekakkan telinga pemain dan orang di sekitarnya
💡 🧠

Analogi Dunia Nyata:

Seperti remote TV: kamu punya tombol Mute untuk mematikan suara saat ada orang lain yang sedang berbicara!

Mengenal Balok Kunci: Loop Musik Latar Tanpa Henti 🧩

Untuk mengaktifkan logika ini di Scratch, kita menggunakan rangkaian balok khusus berikut ini:

  • 🟡 Event: Mulai saat bendera hijau diklik
  • 🔵 Motion / Logika: play sound [BGM] until done
  • 🟣 Kondisi: set volume to (0%)
  • 🔄 Loop: Membungkus kode dalam perulangan agar berjalan terus-menerus
📦 Kode Blok Utama Scratch:
when 🏴 clicked
forever {
  play sound [BGM Loop] until done
}

Langkah Perakitan: Merakit Tombol Mute Interaktif 🛠️

Sekarang kita rangkai langkah-langkah praktiknya satu per satu di Scratch Studio kita!

  • 1️⃣ Buat sprite tombol speaker dengan 2 kostum: Speaker ON dan Speaker OFF
  • 2️⃣ Tempatkan di pojok kanan atas layar panggung
  • 3️⃣ Saat sprite tombol diklik: balik status variabel Mute (0 menjadi 1, 1 menjadi 0)
  • 4️⃣ Atur volume Scratch: jika Mute = 1, volume 0%. Jika Mute = 0, volume 100%!
⚙️ Alur Instruksi:
when this sprite clicked
if <Mute = 0> then
  set [Mute] to (1)
  set volume to (0)%
  switch costume to [Icon Mute]
else
  set [Mute] to (0)
  set volume to (100)%
  switch costume to [Icon Sound]

Dokter Kode: Tips Mengatasi Bug 🐛

Setiap programmer pasti pernah menemui bug. Mari pelajari cara menemukan dan memperbaikinya!

  • 🐛 Bug: Lagu berputar tumpang tindih ratusan kali dan memekakkan telinga.
    Solusi: Gunakan blok play sound UNTIL DONE, jangan gunakan start sound di dalam forever loop!
  • 🐛 Bug: Tombol Mute tidak berfungsi mematikan suara.
    Solusi: Cek apakah blok set volume to (0)% sudah terpanggil.
  • 🐛 Bug: Kostum tombol tidak berganti saat diklik.
    Solusi: Periksa nama kostum pada blok switch costume to.
🛡️ Tips Dokter Kode:

Gunakan selalu 'play sound ... until done' di dalam perulangan musik agar Scratch menunggu lagu selesai sebelum mengulanginya dari awal!
