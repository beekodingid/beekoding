Konsep Dasar • Audio Game & Kenyamanan Pemain
⏱️ Menit ke 10–22

Atmosfer Game: Musik Latar vs Kontrol Pemain 🎶

Musik latar (BGM) membuat game terasa hidup dan seru! Tetapi pemain juga butuh ketenangan saat bermain di malam hari atau tempat umum. Tombol Mute memberikan kendali penuh kepada pemain!

  • 📻 BGM (Background Music): Mengalun lembut tanpa mengganggu efek suara utama
  • 🔊 Status Aktif: Volume 100%, tombol menampilkan ikon suara menyala
  • 🔇 Status Mute: Volume 0%, tombol menampilkan ikon suara tersilang
  • 🔄 Toggle: Satu tombol yang berganti fungsi setiap kali ditekan!

Balok Kunci: Loop Musik Latar Tanpa Putus 🧩

Agar musik latar tidak berhenti di tengah permainan, letakkan balok play sound until done di dalam blok pengulangan forever pada sprite panggung (Stage)!

  • 🚩 when ⚑ clicked: Memulai audio saat permainan dimulai
  • 🔊 set volume to (100) %: Memastikan suara aktif di awal game
  • 🔄 forever [play sound until done]: Memutar lagu sampai selesai, lalu mengulang otomatis dari awal
  • 🛡️ Penting: Jangan gunakan start sound biasa tanpa until done!

Tombol Mute: Sentuhan Klik & Dua Kostum ⚡

Sprite Tombol Mute diletakkan di sudut layar panggung. Saat sprite ini diklik, komputer memeriksa volume: jika sedang bersuara maka di-mute (0%), dan jika sedang mute maka diaktifkan kembali (100%)!

  • 🖱️ when this sprite clicked: Mendeteksi klik langsung pemain
  • ⚖️ if <volume = 0>: Memeriksa apakah status suara sedang mati
  • 👗 switch costume to [SoundOn / SoundMute]: Indikator visual instan
  • 🔊 set volume to (0 / 100)%: Membungkam atau membunyikan seluruh game

Prinsip UX • Desain Ramah Pengguna

Pilar UX: Empati Programmer pada Pemain ❤️

Apa itu User Experience (UX)? UX adalah bagaimana perasaan pemain saat memainkan game kita. Game yang hebat bukan cuma gambarnya bagus, tetapi juga nyaman dan mudah dikontrol!

  • 👂 Telinga Nyaman: Musik tidak boleh memekakkan telinga (terlalu keras)
  • 🎯 Mudah Diakses: Tombol suara ditaruh di tempat yang terlihat jelas (pojok atas)
  • 👀 Umpan Balik Visual: Pemain langsung tahu status suara dari bentuk ikon tombol
  • 🤝 Beri Pilihan: Jangan paksa pemain mendengarkan suara jika situasinya tidak memungkinkan!

Siklus Sistem: BGM Berjalan & Respon Tombol 🗺️

Di Scratch, proses pemutaran musik dan pendeteksian tombol berjalan secara serentak (paralel):

  1. 1️⃣ Jalur 1 (Stage): Memutar lagu BGM terus-menerus tanpa henti
  2. 2️⃣ Jalur 2 (BtnMute): Menunggu interaksi klik dari jemari pemain
  3. 3️⃣ Pemain Klik Tombol: Nilai volume berganti antara 100% dan 0%
  4. 4️⃣ Sinkronisasi: Musik tetap berputar dalam hening, dan terdengar lagi saat di-unmute!

Klinik Debugging • Mencegah Glitch Audio
⏱️ Menit ke 74–82

Dokter Kode: Glitch Musik Rusak vs Mulus 🩺

Kesalahan paling umum yang membuat telinga pemain sakit: memakai balok suara yang salah di dalam loop pengulangan!

  • ❌ Kesalahan Fatal: forever [start sound] tanpa until done ➔ Lagu diulang 30x per detik hingga terdengar seperti suara dengungan rusak!
  • ✅ Solusi Tepat: forever [play sound until done] ➔ Lagu diputar sampai tamat baru diulang
  • ❌ Tombol Tidak Berubah: Lupa memasang switch costume ➔ Pemain bingung apakah tombol berfungsi
  • ✅ Feedback Visual: Selalu beri perubahan ikon agar pemain yakin!
