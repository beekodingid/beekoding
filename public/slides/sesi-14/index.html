Mengapa Kita Butuh Game Juice (Sensasi Game Hidup)? 🤔

Game Juice adalah sentuhan estetika kecil seperti kilauan, getaran, dan animasi yang membuat game biasa terasa sangat memuaskan dimainkan!

  • ✨ Bukan cuma mekanik: Game butuh 'rasa' yang menyenangkan saat pemain berhasil
  • 🧬 Kloning Sprite: Membuat duplikat sprite otomatis tanpa menambah sprite baru
  • 👻 Ghost Effect: Mengubah transparansi objek dari terlihat (0) hingga tembus pandang (100)
  • 🎈 Floating Score: Teks skor melayang naik ke atas lalu perlahan menghilang
💡 🧠

Analogi Dunia Nyata:

Bayangkan makan kerupuk yang renyah vs kerupuk melempem. Game Juice adalah kerenyahan yang membuat pemain ingin terus bermain!

Mengenal Balok Kunci: Kloning Sprite & Ghost Effect 🧩

Untuk mengaktifkan logika ini di Scratch, kita menggunakan rangkaian balok khusus berikut ini:

  • 🟡 Event: Mulai saat bendera hijau diklik
  • 🔵 Motion / Logika: create clone of [myself]
  • 🟣 Kondisi: when I start as a clone
  • 🔄 Loop: Membungkus kode dalam perulangan agar berjalan terus-menerus
📦 Kode Blok Utama Scratch:
when I start as a clone
repeat (10) {
  change y by (4)
  change ghost effect by (10)
}
delete this clone

Langkah Perakitan: Membuat Sprite Teks Skor Terapung 🛠️

Sekarang kita rangkai langkah-langkah praktiknya satu per satu di Scratch Studio kita!

  • 1️⃣ Buat sprite baru berupa teks '+1' berwarna kuning cerah
  • 2️⃣ Saat game mulai: sembunyikan sprite aslinya (hide)
  • 3️⃣ Saat apel ditangkap: buat klon (create clone of [TextSkor])
  • 4️⃣ Pada klon: munculkan di koordinat apel, meluncur naik sambil memudar!
⚙️ Alur Instruksi:
when 🏴 clicked -> hide

when I receive [Apel Tertangkap]
go to [Apple]
create clone of [myself]

Respons Permainan: Percikan Bintang Partikel ⚡

Game terasa hidup jika merespons aksi pemain secara instan dengan efek suara dan perubahan visual!

  • 🔊 Efek Audio: Suara gemerlap 'Magic Coin / Bell' saat klon partikel meledak
  • 🎨 Animasi Visual: 5 partikel bintang meluncur ke arah acak lalu menghilang
  • ⚡ Umpan Balik Instan: Pemain langsung tahu aksi mereka berhasil
  • 🎮 Kenyamanan Bermain: Gameplay terasa halus dan memuaskan
🔊 ✨

Umpan Balik Pemain:

Setiap tangkapan apel menghasilkan sensasi visual ceria yang membuat pemain merasa dihargai atas prestasinya!

Fitur Tingkat Lanjut: Partikel Bintang Berputar 🚀

Tambahkan efek putaran sudut (turn 15 degrees) pada partikel saat melayang untuk animasi yang lebih dinamis!

  • ⭐ Ubah ukuran partikel secara acak (set size to random 40 to 80%)
  • 🎨 Ganti warna partikel dengan change color effect by 25
  • ⏱️ Selalu hapus klon di akhir agar tidak memenuhi memori komputer
🌟 Fitur Tambahan:
repeat (8) {
  move (5) steps
  turn ↻ (15) degrees
  change ghost effect by (12)
}
delete this clone

Dokter Kode: Tips Mengatasi Bug 🐛

Setiap programmer pasti pernah menemui bug. Mari pelajari cara menemukan dan memperbaikinya!

  • 🐛 Bug: Klon menumpuk dan layar macet.
    Solusi: Pastikan selalu ada blok delete this clone di akhir skrip klon!
  • 🐛 Bug: Teks skor muncul terus di tengah layar.
    Solusi: Sprite asli harus di-hide saat bendera hijau diklik.
  • 🐛 Bug: Klon tidak terlihat.
    Solusi: Pasang blok show tepat setelah when I start as a clone.
🛡️ Tips Dokter Kode:

Scratch memiliki batas maksimal 300 klon. Selalu hapus klon yang sudah selesai beranimasi agar game tidak lag!
