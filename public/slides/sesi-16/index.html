Misi Baru: Waspada Apel Beracun! ❤️

Selamat datang di STAGE 2: SESI 16! Hari ini kita akan mempelajari logika nyawa (health heart) & buah beracun untuk membawa game kita ke level berikutnya!

  • 🎯 Tujuan Utama: Membuat mekanisme 3 nyawa hati dan rintangan buah beracun yang harus dihindari.
  • 🧩 Balok Kunci: set [Nyawa] to (3)
  • 💡 Konsep Baru: Health System
  • 🚀 Hasil Akhir: Proyek interaktif yang siap dimainkan dan dipamerkan!

Mengapa Kita Butuh Sistem Nyawa & Hati? 🤔

Dalam game seru, pemain tidak hanya mengejar skor, tapi juga harus berhati-hati menghindari bahaya yang bisa mengurangi nyawa!

  • ❤️ Memulai ronde dengan 3 Nyawa
  • ☠️ Menangkap apel ungu beracun mengurangi 1 nyawa
  • 💥 Jika nyawa habis (0), game berakhir seketika
  • 🛡️ Ada jeda kebal sejenak agar nyawa tidak langsung ludes
💡 🧠

Mengenal Balok Kunci: Pengurangan Nyawa & Deteksi Bahaya 🧩

Untuk mengaktifkan logika ini di Scratch, kita menggunakan rangkaian balok khusus berikut ini:

  • 🟡 Event: Mulai saat bendera hijau diklik
  • 🔵 Motion / Logika: set [Nyawa] to (3)
  • 🟣 Kondisi: if touching [Poison] then change [Nyawa] by (-1)
  • 🔄 Loop: Membungkus kode dalam perulangan agar berjalan terus-menerus
📦 Kode Blok Utama Scratch:
if <touching [Poison]?> then
  change [Nyawa] by (-1)
  start sound [Oops]
  if <Nyawa < 1> then broadcast [Game Over]

Fitur Tingkat Lanjut: Efek Berkedip Kebal (Invincibility) 🚀

Setelah terkena racun, mangkuk berkedip selama 1 detik dan kebal dari racun berikutnya.

  • 🛡️ Mencegah pengurangan nyawa beruntun yang tidak adil
  • 👻 Gunakan loop repeat (5) [set ghost to 50, wait 0.1, set ghost to 0]
  • 🎮 Gameplay terasa jauh lebih seimbang dan profesional
🌟 Fitur Tambahan:
repeat (4) {
  set ghost effect to (60)
  wait (0.1) secs
  set ghost effect to (0)
  wait (0.1) secs
}

Dokter Kode: Tips Mengatasi Bug 🐛

Setiap programmer pasti pernah menemui bug. Mari pelajari cara menemukan dan memperbaikinya!

  • 🐛 Bug: Sekali sentuh racun, 3 nyawa langsung lenyap sekaligus.
    Solusi: Langsung pindahkan apel beracun ke atas atau beri delay wait 0.5 secs!
  • 🐛 Bug: Game Over tidak muncul saat nyawa 0.
    Solusi: Cek pembanding: if <Nyawa < 1> (artinya saat nyawa = 0).
  • 🐛 Bug: Apel beracun dan apel merah jatuh bersamaan di titik sama.
    Solusi: Beri nilai pick random posisi X dan delay kemunculan yang berbeda.
🛡️ Tips Dokter Kode:

Setiap deteksi tabrakan yang mengurangi nilai harus memiliki pemisah (delay atau teleport) agar tidak terhitung berkali-kali dalam 1 detik!
