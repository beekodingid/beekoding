Percabangan: Jika & Maka (If-Then) ⚡

Komputer membuat keputusan cerdas menggunakan balok if <...> then. Saat target tercapai atau bahaya terjadi, balok di dalamnya langsung dijalankan!

  • 🔍 Sensor Deteksi: Memeriksa sentuhan atau angka variabel
  • 🎯 Aksi Instan: Menambah skor, membunyikan audio, atau pindah level
  • 🛡️ Keamanan: Memastikan game tetap berjalan stabil tanpa bug
if touching Bowl ▾ ? then
start sound Chomp ▾
change Skor ▾ by 1
broadcast AksiBerhasil ▾

Dokter Kode: Tips Memperbaiki Error 🐛

Programmer hebat tidak pernah takut dengan error! Perhatikan perbandingan kode salah vs benar berikut ini agar game berjalan sempurna:
