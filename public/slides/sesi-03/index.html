Susunan Kode Inti • Formula Beeby Ajaib
⏱️ Menit ke 36–48

Susun 3 Balok Spektakuler! 🧩

Sekarang satukan balok kuning, balok ungu, dan balok merah muda:

👆 when this sprite clicked
change size by 20
🔊 start sound Magic Spell ▼

Setiap kali diklik: Beeby akan membesar 20 angka sambil bersuara ting-ting-ting!

🔍 Apa Bedanya:

🟣 set size to 100%: Ukuran langsung dipatok pas 100.

🟣 change size by 20: Ukurannya BERTAMBAH gemuk terus setiap diklik!

Pastikan balok suara yang dipilih adalah 'start sound', bukan 'play sound until done'.

Tantangan: 3 Bunga Musik 🌷🌻🌸

Trik Programmer • Jurus Kembalikan Ukuran Normal
⏱️ Menit ke 70–78

Jurus Rahasia: Tombol Reset 🔄

"Kak! Beeby-ku diklik terus sampai badannya menutupi seluruh layar laptop! Gimana cara ngecilinnya lagi?"

🚩 when green flag clicked
set size to 50 %
💡

Kunci Sukses:

Pasang kode ini di Beeby! Kapan pun Beeby terlalu raksasa, cukup klik Bendera Hijau 🚩, dia langsung kembali imut ke 50%!

🐘 ➔ 🚩 ➔ 🐝

Dari Raksasa Jadi Imut!

Bendera hijau berfungsi sebagai tombol restart permainan!

Konsep ini penting: Membedakan 'Change size by' vs 'Set size to'.
