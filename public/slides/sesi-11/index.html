Mekanika Gerak Musuh

Meluncur Mulus dengan Blok Glide 🪁

Perbedaan antara gerak teleportasi mendadak vs meluncur halus:

⚡ Blok "Go to" (Teleportasi)
go to x: 0 y: 50

Sprite langsung berpindah sekejap mata dalam 0 detik seperti pesulap. Kurang cocok untuk musuh patroli.

🕷️ Blok "Glide" (Meluncur Halus)
glide 2 secs to x: 0 y: 50

Sprite meluncur anggun selama 2 detik dari titik A ke titik B. Sangat pas untuk laba-laba yang menjaga lorong!

Konsep Koding Utama

Siaran Radio Rahasia: Broadcast Message 📢📻

Bagaimana Beeby memberi tahu layar panggung bahwa ia kalah?

📢 1. PENGIRIM (Siarkan Pesan)
broadcast Game Over ▾

Saat Beeby menabrak laba-laba, Beeby berteriak ke mikrofon: "Perhatian seluruh panggung, aku terkena laba-laba! Siarkan Game Over!"

👂 2. PENERIMA (Merespons Pesan)
when I receive Game Over ▾

Layar Backdrop mendengarkan siaran radio itu, lalu langsung mengganti tampilan menjadi layar gelap Game Over!

Studio Desain Layar

Mendesain Layar Kalah & Layar Menang 🎨🏁

Buat 2 backdrop baru di Scratch menggunakan alat Teks:

💀 1. Layar Kalah (Backdrop: Game Over)

• Latar belakang warna hitam / merah gelap pekat.

• Tuliskan teks besar berwarna merah: "GAME OVER".

• Tambahkan teks kecil: "Tekan Bendera Hijau untuk coba lagi!"

🏆 2. Layar Menang (Backdrop: You Win)

• Latar belakang warna kuning emas / biru cerah ceria.

• Tuliskan teks besar bercahaya: "YOU WIN!".

• Tambahkan ikon piala atau bintang kemenangan.

Detektif Bug Cilik

3 Bug Paling Sering Terjadi pada Broadcast 🕵️‍♂️🔍

Solusi cerdas saat alur game over-mu macet:

🛑🕷️

Laba-Laba Meluncur Sekali Lalu Mogok

Lupa membungkus blok glide di dalam loop forever! Agar terus berpatroli, wajib ada loop selamanya.

💀🚩

Game Baru Mulai Tapi Langsung Game Over

Lupa mengatur backdrop awal! Pasang switch backdrop to [Labirin] di bawah bendera hijau panggung.

🏆❓

Skor Penuh Tapi Tidak Muncul Layar Menang

Cek kondisi kemenangan: if <Skor = 6> then [broadcast You Win]. Pastikan angkanya sesuai jumlah bungamu!
