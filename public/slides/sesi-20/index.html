Mengapa Kita Butuh Sistem Rekor Tertinggi? 🤔

Mengapa kita ingin main lagi setelah kalah? Karena ada rekor angka tertinggi yang ingin kita kalahkan! Itulah kekuatan psikologi High Score!

  • 📊 Variabel 1: Skor Sekarang (Reset ke 0 setiap ronde)
  • 🏆 Variabel 2: Rekor Tertinggi (Menyimpan nilai terbaik)
  • ⚖️ Operator > (Lebih Besar): Mengecek apakah skor baru melampaui rekor lama
  • 🎉 Selebrasi instan saat rekor baru berhasil dipecahkan!
💡 🧠

Analogi Dunia Nyata:

Seperti mistar lompat tinggi: setiap kali ada atlet melompat lebih tinggi, mistar dinaikkan ke rekor yang baru!

Mengenal Balok Kunci: Rumus Emas Pembanding Rekor 🧩

Untuk mengaktifkan logika ini di Scratch, kita menggunakan rangkaian balok khusus berikut ini:

  • 🟡 Event: Mulai saat bendera hijau diklik
  • 🔵 Motion / Logika: if HighScore> then
  • 🟣 Kondisi: set [HighScore] to (Skor)
  • 🔄 Loop: Membungkus kode dalam perulangan agar berjalan terus-menerus
📦 Kode Blok Utama Scratch:
if <Skor > HighScore> then
  set [HighScore] to (Skor)
  broadcast [Rekor Baru]
  start sound [Cheer Applause]

Langkah Perakitan: Menampilkan Papan Skor di Layar 🛠️

Sekarang kita rangkai langkah-langkah praktiknya satu per satu di Scratch Studio kita!

Dokter Kode: Tips Mengatasi Bug 🐛

Setiap programmer pasti pernah menemui bug. Mari pelajari cara menemukan dan memperbaikinya!

  • 🐛 Bug: High Score selalu kembali ke 0 setiap kali game dimulai ulang.
    Solusi: Hapus blok set [HighScore] to (0) dari bawah bendera hijau!
  • 🐛 Bug: Rekor baru tidak terpicu meski skor sudah lebih tinggi.
    Solusi: Pastikan menggunakan operator tanda lebih besar (>), bukan lebih kecil (<).
  • 🐛 Bug: Suara tepuk tangan berbunyi berulang-ulang tanpa henti.
    Solusi: Pasang syarat penanda agar suara hanya berbunyi 1 kali saat rekor pecah.
🛡️ Tips Dokter Kode:

Memori variabel yang tidak di-reset saat start adalah cara Scratch menyimpan data sementara antar ronde permainan!
