Papan Peringkat Sederhana: High Score System! 🏆

Selamat datang di STAGE 2: SESI 20! Hari ini kita memprogram fitur legendaris yang ada di setiap game arkade: Membandingkan Nilai untuk Mencatat Rekor Tertinggi (High Score). Belajar logika perbandingan dan motivasi pantang menyerah untuk memecahkan rekor terbaikmu sendiri!

🎯 Misi Utama Hari Ini:
  • 🏆 Konsep & Inti: Membandingkan nilai: if Skor > HighScore then set HighScore to Skor
  • ⌨️ Instruksi / Kode: Memotivasi anak untuk terus mencoba memecahkan rekor sendiri
  • 💾 Penyimpanan Sesi: Menjaga nilai HighScore agar tidak hilang saat main ulang
  • 🎉 Game Juice: Selebrasi suara & efek animasi saat rekor baru berhasil dipecahkan!
Konsep Dasar • Logika Rekor Tertinggi
⏱️ Menit ke 10–22

Analogi Juara: Rekor Hanya Berubah Jika Terlampaui 🤔

Bayangkan papan rekor atlet dunia! Rekor terbaik tidak akan pernah turun. Jika kamu mencetak skor lebih tinggi, rekor lama tergeser dan rekor barumu dicatat dengan bangga!

  • 🥇 Skor Saat Ini: Nilai yang baru saja kamu peroleh di ronde ini
  • 🏆 HighScore: Catatan nilai tertinggi yang pernah diraih sebelumnya
  • ⚖️ Uji Perbandingan: Komputer mengecek apakah Skor > HighScore
  • ✨ Hasil: Jika LEBIH BESAR, simpan angka baru dan rayakan kemenangan!

Bedah Balok Kode • Variabel Skor vs HighScore
⏱️ Menit ke 22–32

Balok Kunci: Jangan Reset HighScore ke 0! 🧩

Inilah perbedaan paling mendasar antara skor biasa dan rekor tertinggi: Skor selalu direset ke 0 saat permainan dimulai, tetapi HighScore dibiarkan tetap menyimpan rekor sebelumnya!

  • 🚩 when ⚑ clicked: Memulai permainan baru
  • 🔄 set [Skor ▾] to (0): Mengosongkan skor pemain untuk ronde baru
  • 🔒 HighScore Tetap Utuh: JANGAN letakkan balok reset untuk HighScore!
  • 👁️ show variable [HighScore ▾]: Tampilkan di layar agar pemain tertantang!
when 🏴 clicked
set Skor ▾ to 0
show variable HighScore ▾
show variable Skor ▾

Mekanik Inti • Operator Lebih Besar Dari (>)
⏱️ Menit ke 32–42

Logika Pembanding: if Skor > HighScore ⚡

Saat ronde permainan berakhir (Game Over), komputer menjalankan perintah perbandingan. Jika skor yang baru diperoleh lebih besar daripada rekor lama, komputer langsung memperbarui nilai rekor!

  • 📩 when I receive [GameOver ▾]: Diperiksa saat ronde selesai
  • 🟢 Operator > (Hijau): Membandingkan apakah nilai kiri lebih besar dari kanan
  • 📝 set [HighScore ▾] to (Skor): Rekor lama digantikan dengan skor baru
  • 🧠 Pola Berpikir: Mengajarkan anak konsep evaluasi kondisi relasional
when I receive GameOver ▾
if Skor > HighScore then
set HighScore ▾ to Skor
start sound VictoryFanfare ▾

⏱️ Menit ke 42–52

Pemberian Apresiasi: Pesta Rekor Baru 🎉

Memberikan umpan balik instan sangat penting untuk membangun kepercayaan diri anak! Tambahkan kata-kata apresiasi dan efek suara meriah agar anak bersemangat mencoba lagi.

  • 💬 say [🎉 REKOR BARU! 🎉] for (2) secs: Dialog bangga dari karakter
  • 📢 broadcast [PestaRekor ▾]: Memicu animasi piala atau kembang api
  • 💪 Pesan Penyemangat: Jika belum rekor baru, katakan: "Ayo coba lagi!"
  • 🔄 Loop Motivasi: Anak tertantang untuk bermain berkali-kali

Algoritma Game • Siklus Lengkap Sistem High Score
⏱️ Menit ke 52–62

Siklus Sistem: Bermain ➔ Bandingkan ➔ Rekor Baru 🗺️

Berikut alur logika permainan yang mendorong anak terus berlatih dan berkembang:

  1. 1️⃣ Mulai Ronde: Skor = 0, tetapi HighScore tetap angka rekor lama
  2. 2️⃣ Kumpulkan Poin: Pemain mengumpulkan skor sebanyak-banyaknya
  3. 3️⃣ Game Selesai: Evaluasi relasional: Apakah Skor > HighScore?
  4. 4️⃣ Pecah Rekor? Ya ➔ Update HighScore + Selebrasi | Belum ➔ Motivasi main lagi!

Klinik Debugging • Menjaga Integritas High Score
⏱️ Menit ke 74–82

Dokter Kode: 3 Kesalahan Umum High Score 🩺

Tiga jebakan logika yang sering dialami kreator cilik saat membuat sistem rekor tertinggi:

  • ❌ Jebakan 1: Mereset HighScore ke 0 di bendera hijau ➔ Rekor selalu hilang!
  • ❌ Jebakan 2: Memakai operator < (Lebih Kecil) ➔ HighScore malah mengecil!
  • ❌ Jebakan 3: Terbalik: set Skor to HighScore ➔ Skor pemain tertimpa!
  • ✅ Kunci Benar: if Skor > HighScore then set HighScore to Skor!
